Terraform Ansible GitLab Integration

This project provisions AWS infrastructure with Terraform and is designed to support automation through GitLab CI/CD and Ansible.

Project Overview

  • Creates AWS EC2 instance resources.
  • Configures security group rules.
  • Uses an AWS key pair for SSH access.
  • Can generate a local hosts file for Ansible.

Basic Terraform Commands

  • terraform init
  • terraform validate
  • terraform plan
  • terraform apply
  • terraform destroy
